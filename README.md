🛒 Ecommerce REST API

A scalable and secure Ecommerce Backend API built with Laravel, designed to support real-world online store functionalities.

This project demonstrates clean backend architecture, secure authentication, and modern ecommerce features.

🚀 Key Features

RESTful APIs for:

User Authentication

Product Management

Cart & Wishlist

Order Processing

Secure API authentication using Laravel Sanctum

Role-Based Access Control (Admin, Vendor, Customer)

bKash Payment Gateway integration for checkout

Optimized database queries using Eloquent Relationships

Centralized validation & standardized JSON responses

Database version control using Migrations & Seeders

Clean code following MVC Architecture

🛠 Tech Stack

Backend: Laravel, PHP

Database: MySQL

Authentication: Laravel Sanctum

API Type: REST API

Tools: Postman, Git

📌 Why This Project?

Built with real-world ecommerce requirements in mind

Secure, scalable, and easy to integrate with frontend/mobile apps

Demonstrates strong backend fundamentals & API design skills
